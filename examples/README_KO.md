# 예제 파일 주의

이 폴더의 `demo-build.json`, `example-events.json` 등은 기존 기능을 시험하기 위한 예제 입력입니다. 실제 게임에서 획득한 장비나 DPYes로 측정한 로그가 아니며, 실제 피해량을 입증하지 않습니다.

v2 빌드를 가져오면 검색 DB에 연결된 아이템 레코드는 재사용할 수 있지만, 이름만 적힌 수동 템플릿은 실제 DB에서 다시 선택해야 합니다. 기존 수동 계산 모드와 v3 자동 모드는 구분됩니다. v3 자동 배분을 사용하려면 DB를 준비한 후 캐릭터·스킬·별자리에서 배분하세요.

실제 빌드 공유는 앱의 JSON 저장을 사용하세요. DB 포함 HTML 저장은 장비 DB와 현재 배분·이름·메모까지 담을 수 있습니다.
